# 微信群言论监控助手

> 武汉同辰科技有限公司 业务电话：15001168567

监控微信群聊天区域，识别不当言论并报警提醒；可选自动 @ 发言人回复提醒。

## 快速开始

### 方式一：直接跑源码

```bash
pip install -r requirements.txt
python main.py          # Windows 下也可双击 run.bat
```

需要 Python 3.9+（Windows 实测 3.13 可用）。首次启动约需 3~10 秒加载 OCR 模型。

### 方式二：用打包好的 exe

见文末「打包发布」，产物为目录版 exe，免安装、免 Python 环境。

### 使用步骤

1. **圈选监控区域**：点击"圈选监控区域"，屏幕变暗后像 EV 录屏一样拖拽框选微信聊天窗口的**消息区域**（不要包含输入框）。
   - 选框支持拖动内部移动、拖 8 个手柄调整大小、底部宽高输入框精确设定、回车/双击确定、Esc 取消。
   - 确定后**监控框常驻屏幕**（蓝色虚线框 + 角标 + "监控中 宽x高"标签）。不想看可在主界面取消勾选"屏幕上显示监控框"。
   - **移动 / 跨屏幕移动监控框**（不用重新圈选）：
     - 默认**锁定**：框为鼠标穿透状态，方便正常用微信。
     - 取消勾选「锁定监控框位置」后，框变橙色可操作：拖框内移动、拖 8 个手柄缩放、方向键微调（Shift 加速 10px）、**双击框内重新锁定**。
     - 也可以在主界面选「屏幕 #N」+ 点「移到该屏」，监控框直接搬到另一块显示器（居中放置）。
     - 移动过程中若监控正在运行，区域会**自动热切换**（首帧按历史消息处理，不会把整屏旧消息误报一遍）。
   - 多屏注意：坐标使用虚拟桌面坐标（副屏可能在主屏左侧、坐标为负），跨屏拖动不会错位。若某屏缩放不是 100%，可能出现几像素偏差，把该屏缩放调成 100% 最稳。
2. **配置两级判定**（默认只用第一级规则库即可工作）：
   - **第一级 规则库**：辱骂攻击 / 人身威胁 / 广告引流 / 色情低俗 / 政治有害 / 刷屏，命中即判，零成本秒判，**不依赖大模型**。可在界面里直接改（每行一条正则，`[类别]` 指定归属）。
   - **第二级 大模型复核**：勾选"启用大模型"+填写接口后，只对"未命中规则但含可疑信号"的消息做语义复核，用于识别软广、变体辱骂，同时排除误伤（如引用脏话讨论）。
     - 接口预设下拉框可选「豆包(火山方舟) / DeepSeek / 智谱 / Moonshot」。
     - **豆包(火山方舟)注意**：模型一项必须填控制台创建的**推理接入点 ID**（形如 `ep-2024xxxxxx-xxxxx`），不是模型名。
     - 连不上时运行 `python tests/test_llm.py` 看接口完整报错。
   - 复核范围可选：只复核可疑消息（推荐）/ 全部送大模型 / 不用大模型。
   - **自测**：点"自测一段文字"，粘贴一句真实消息，立刻看到它会怎么判、走的哪一级。
3. **选择模式**：
   - `仅提醒`（推荐先用）：发现不当言论 → Windows 弹窗 + 提示音 + 报警记录 + 证据截图，**不动鼠标**。
   - `自动@用户回复`：在提醒基础上，自动右键该消息 → 选"@TA/提醒" → 粘贴回复文字 → 回车发送。实验性功能，建议观察一段时间后再开启。
4. **保存设置**，点击**开始监控**。最小化窗口后程序继续在后台运行（托盘图标）。

## 消息从出现到报警的完整链路

```
截图(每1~2秒) → OCR识别文字+坐标 → 折行合并(同一消息多行拼回一条) → 增量去重(只留新出现的)
   → L1 规则库(辱骂/威胁/广告/色情/政治/刷屏，命中即判)
   → L2 大模型复核(仅未命中且含可疑信号的消息)
   → warn/severe → 弹窗+提示音+存证（同一内容本次运行只提醒一次）
```

**为什么某条消息没报警**（按顺序排查）：

1. 它是**图片/二维码/名片**（无文字可 OCR）——当前版本只能识别文字消息。
2. 开始监控时它**已经在屏幕上**——首帧视为历史消息，只监控新出现的。
3. 它没命中任何规则，且大模型没启用或没判为不当——用「自测一段文字」验证。
4. 监控区没框住它，或消息已滚出框选区域。
5. 同一内容本次运行已提醒过（只记日志，不重复弹窗）。

## 注意事项

- **首帧不判定**：开始监控时画面上已有的消息视为历史，只监控新出现的消息。
- **自动@回复的兼容性**：右键菜单中"@TA/提醒"的文字因微信版本（3.x / 4.x）而异。如果自动回复提示"未找到菜单项"，把微信右键消息菜单里实际的 @ 选项文字加进 `config.json` 的 `menu_keywords`。
- **紧急中断**：自动回复执行过程中，把鼠标快速甩到屏幕**左上角**可立即中断。
- **增量去重**：消息只要在屏幕上（哪怕停留几小时）就只判定一次；须滚出屏幕 10 分钟后再次出现才会重新判定（`config.json` 的 `dedup_expire_sec`）。开始监控时已在屏上的内容视为历史消息不判定，可点「重判当前屏幕内容」补判。
- **重复提醒策略**：主界面「同一内容重复出现」可选——本次运行只提醒一次（默认）/ 冷却 10 或 30 分钟后再提醒 / 每次重新出现都提醒。被抑制的重复只记日志（报警记录动作列会显示原因），不弹窗、不响铃。
- **刷屏判定**：同一句话同屏出现 3 次即判不当（阈值可调）。
- 仅建议用于自己管理的群、正常的群规管理场景；所有数据仅存储在本机。

## 打包发布

双击 `build.bat` 或运行：

```
pyinstaller --noconfirm --noconsole --clean --name WeChatMonitor --collect-all rapidocr_onnxruntime main.py
```

产物在 `dist\WeChatMonitor\`，整个文件夹打 zip 发给用户即可（免安装，双击 WeChatMonitor.exe 运行）。

## 技术说明

- OCR 使用 RapidOCR（PP-OCR 模型 + onnxruntime，纯本地推理，不上传图片）。
- 大模型判定走你配置的 API，只发送 OCR 出的文字，不发送截图。
- 依赖见 `requirements.txt`。

## 首次使用请复制配置模板

```bash
cp config.example.json config.json
```

`config.json` 含 API Key 等敏感信息，**已在 `.gitignore` 中排除，切勿提交**。
